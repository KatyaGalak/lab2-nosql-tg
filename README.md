## Telegram-бот для бронирования помещений университета

Клиент к [бэкенду лабораторной работы №2](https://github.com/KatyaGalak/lab2-nosql): бот не хранит данные сам,
а работает через его REST API. Через бота пользователи бронируют аудитории и коворкинги,
а администратор рассматривает заявки.

### Возможности
- регистрация и вход по номеру ИСУ;
- просмотр помещений и их занятости;
- бронирование в пошаговом диалоге: выбор организации (или «лично»), проверка даты, времени, вместимости и телефона;
- временная корзина заявок и отправка на рассмотрение;
- просмотр заявки с историей статусов и комментариями, комментарии к заявке;
- поиск заявок по автору и статусу;
- для администратора: одобрение и отклонение заявок с комментарием или причиной, отчёт по организациям.

### Основные команды
| Команда | Что делает |
|---|---|
| `/register`, `/login <ИСУ>` | регистрация и вход |
| `/rooms`, `/room <id>` | помещения и их занятость |
| `/book` | новая заявка (пошаговый диалог) |
| `/cart`, `/checkout` | корзина и отправка заявок на рассмотрение |
| `/bookings`, `/booking <id>` | список заявок и карточка заявки |
| `/search [ИСУ] [статус]` | поиск заявок по автору и статусу |
| `/comment <id>` | комментарий к заявке |
| `/orgs` | организации, от имени которых можно подать заявку |
| `/approve <id>`, `/reject <id>` | решение по заявке (администратор) |
| `/stats` | количество заявок по организациям (администратор) |

Полный список — команда `/help`.

### Запуск
1. Запустить бэкенд (см. его README).
2. Создать файл `.env` в корне проекта:
   ```
   TELEGRAM_BOT_TOKEN=<токен бота от @BotFather>
   ```
3. Запустить бота:
   ```bash
   ./gradlew bootRun
   ```

Для работы нужен доступ к `api.telegram.org`
